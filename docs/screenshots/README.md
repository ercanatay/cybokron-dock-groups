# Screenshots

Taken from v0.11.0 (dark appearance), cropped to the window with transparent rounded corners, except the two marked v0.5.6.

- `groups-window.png` — The group window: the groups in the sidebar, a group's name, emoji and items, with Add, Sort A→Z, Show Popup, Open All and Hide All.
- `popup-panel.png` — The group popup: apps with a dot under each running one, Open All, Hide All and Force Quit, and the Close All modifier hint.
- `group-switching-triggers.png` — A group's settings: Start and Finish, Keyboard Shortcut and Triggers.
- `group-dock-tile.png` — A group's settings: Dock Tile preview and options, Standalone and Popup overrides.
- `settings-triggers.png` — Settings → Triggers: Open at Login, Status with Pause, Location Access, All Triggers.
- `settings-switching.png` — Settings → Switching: Protected Apps, Start and Finish, Focus.
- `settings-shortcuts.png` — Settings → Shortcuts & Siri: ⌃⌥1…9, assigned groups, group shortcuts.
- `settings-updates.png` — Settings → Updates: automatic checks, current version, Check Now, Other Versions….
- `settings-other-versions.png` — Other Versions…: the published releases with Install.
- `popup-filter.png` — (v0.5.6) The popup filtered by typing “mic”; Return opens the selected app.
- `about.png` — (v0.5.6) The About window with social profiles, support links, the app's version and links, and books.
